# Personal Budget & Expense Tracker

## Project Description

The Personal Budget & Expense Tracker is a simple web project designed to help users organize and monitor their expenses. It allows users to view a budget overview, enter expense information, and view sample expenses in a structured table.

This project was developed using HTML5 and CSS3 as part of the Week 2 assignment.

## Features

### 1. Budget Overview
Displays three budget cards:
- Monthly Budget
- Total Expenses
- Remaining Balance

### 2. Add Expense Form
Contains:
- Expense Name input
- Amount input
- Category dropdown with five options:
  - Food
  - Transport
  - Rent
  - Entertainment
  - Other
- Add Expense button

### 3. Expense Table
Displays sample expense records using an HTML table with four columns:
- Name
- Amount
- Category
- Date

The table contains five sample expenses.

### 4. Multimedia Content
- A budget tracker logo using the HTML image element.
- An embedded YouTube video using an iframe.

### 5. Interactive Elements
- A collapsible instructions section using HTML details and summary elements.
- Table row hover effects.
- Button hover styling and pointer cursor.

### 6. CSS Styling
The stylesheet includes:
- Page layout and background styling.
- Budget cards and form styling.
- Table borders and alternating row colors.
- Advanced CSS selectors, including descendant, direct child, positional, negation, and focus selectors.

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. View the budget overview, expense form, expense table, and other page sections.

## Note

This is a static website. The Add Expense button is not yet connected to JavaScript functionality. Dynamic expense management will be introduced in a later project phase.
